# ExpenseFlow

A role-based expense voucher workflow built with React, Express, and SQLite.

## Run locally

```sh
npm install
npm run dev
```

The app is available at `http://localhost:5173`; the API runs at `http://localhost:4000`.
SQLite data is created in `server/data/expenses.sqlite`, and signature images are stored in `server/uploads/`.

For a production build, run `npm run build`, set `NODE_ENV=production` and a strong private `JWT_SECRET`, then run `npm start`. Express serves the built frontend and API on the same port.

## Workflow

- Employees can create and update drafts, upload a signature, and submit a voucher. Only their own vouchers are returned by the API.
- Directors can search and filter all vouchers and approve pending submissions with a signature or reject them with a reason.
- Accounts can search and filter all vouchers and view approved vouchers and both signatures.
- Voucher numbers are generated by the server. The API enforces role permissions, draft-only edits/deletes, and required fields for submission and approval.

Signatures accept PNG, JPEG, or WebP images up to 2 MB. For production, configure a private `JWT_SECRET`, use HTTPS, and move uploads to private object storage with authenticated delivery.
